# Archive

Historical working notes kept for traceability: design-review rounds, internal
audits, superseded plans and decision logs from Astraea's development. They
describe the code at the commits they name, not the current release, and some
of their findings have since been fixed.

For the current state, start with the [README](../../../README.md),
[project status](../project-status.md) and the
[physical contract](../astraea-normative-physical-contract.md).

`audit-data/` holds the machine-readable records those audits produced.
