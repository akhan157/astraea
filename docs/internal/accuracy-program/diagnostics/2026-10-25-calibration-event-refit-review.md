# CAL-E2: event-qualified coast refit — scientific decision, 2026-10-25

**Authorize a bounded successor that explicitly refits after excluding centers with event-contaminated raw neighborhoods.** This corrects a diagnosed mismatch between the inversion's assumed regime and its selected support, conditional on the declared events. It does not establish accurate physical Cd, justify a numerical wind/attitude threshold, or qualify applying the resulting multiplier outside the fitted coast regime. CAL-E1 correctly blocks the existing contaminated selection; changing the selection now must be an explicit, separately identified refit, not a silent reinterpretation of its old coefficient.

## Scientific basis and exact selection contract

The current reconstruction uses `a_drag = −dv_z/dt − g`, ISA density and fixed coast mass (`coastWindow.ts:245–252`). Thrust and recovery in the local polynomial's input invalidate the claimed unpowered, recovery-free interpretation even if the center itself falls between the events. The supplied real-Cosmic log uses centers 2.305–7.278 s but raw support 2.212–7.366 s, overlapping declared recovery at 7.205 s. The model uses centers 2.100–7.450 s and raw support 1.850–7.650 s, including native burnout at 1.860 s. This establishes a concrete selection defect under those event declarations; it does not establish the direction or magnitude of the coefficient bias.

Implement the following deterministic rule separately in each trajectory's own clock:

1. Compute exactly the existing sorted/ascent record, feature proxies, velocity-column versus altitude-derivative method, half-width, inclusive raw neighborhoods, local polynomial coefficients and heuristic candidate centers (`coastWindow.ts:168–228`). Retain the existing low-speed rule and signed inferred accelerations. Do not truncate the input to event bounds before fitting, change the smoothing width, restart the feature search within the allowed interval, add new centers, or shrink a neighborhood to make it fit.
2. For each otherwise usable original center, use the **actual first/last samples consumed by its original local fit**, already tracked at `coastWindow.ts:197–206`. Retain it only if `supportLo >= finalBurnout.latestS` and `supportHi < firstRecovery.earliestS`. This matches the existing eligibility inequalities (`calibrationEligibility.ts:103–108`). Exact burnout equality is permitted only with the stated event meaning “thrust and depletion complete by this time”; recovery equality is excluded. Include timestamp rounding/clock conversion/event uncertainty in the declared bounds; never compare rounded display values.
3. If recovery evidence instead establishes absence through a specified time, use `supportHi <= absentThroughS`. The inclusive meaning of “through” must be explicit. Unknown recovery is not evidence of absence. Missing burnout or recovery coverage keeps the original analysis-only preview available but must not produce a result labeled fully event-qualified; explain the missing evidence. A partial exclusion preview, if supported, must remain explicitly partial/unverified.
4. Refit the same through-origin signed OLS on surviving centers, independently on log and model (`dragFit.ts:68–95`; `calibration.ts:101–133`). Retain the original minimum count, scale bounds and all finite-input checks. No window, event bound, mass, coefficient sign or offset is chosen by residual or apogee outcome.

For uncertain intervals, latest burnout and earliest recovery provide the conservative intersection of admissible coast times. A widened uncertainty interval can only remove or retain centers, never add them. Contradictory/overlapping event bounds or fewer than 10 surviving coast points must report insufficient qualified support, not fall back to the old fit or widen the interval. The surviving set need not be the largest possible physical coast: it is deliberately a subset of the frozen heuristic set. Keeping the original coefficients also retains their smoothing/truncation biases; this correction only removes known event overlap from selected neighborhoods.

## Evidence, application and durable identity

Events and conditions have different jobs. Source-attributed event times allow conditional exclusion; they do not establish approximately vertical air-relative motion, negligible wind/lateral effects, constant mass, correct flown mass/geometry or ISA density. Complete motion and mass review remains necessary **on both sides over the retained raw support** (`calibrationEligibility.ts:109–120`; `CalibrationReview.tsx:81–95`). Native model events establish modeled timing only; log evidence uses the imported log clock, never an apogee-aligned display clock. “Final burnout” must include the last thrust/tail-off, and “first recovery” the first event affecting the reconstruction. Known mass-change intervals continue to override a supportive declaration. Do not merely delete neighborhoods around a separation and pool both sides: a single constant-mass fit across that change remains unsupported. The existing aggregate-support mass-change gate is appropriately conservative.

Provide an explicit **Refit using declared event bounds** action and a separate Apply action. Editing bounds, source/clock attribution, normalized samples, model input identity or estimator selection policy makes a previous refit stale; Apply must not pair its coefficient with new selection evidence. If a refit fails or is canceled, preserve any already-applied project calibration and do not expose a stale candidate as the new result. Snapshot evidence and input identity for asynchronous work and ignore obsolete completion. Condition-only review may reassess eligibility on unchanged support, but stored evidence must correspond to the applied result. If the engine/model changes during the parallel CP work, use matching engine/input identity for each paired before/after comparison; do not attribute engine changes to the selector.

Persist an explicit selection-policy/version identifier in addition to the unchanged polynomial/OLS estimator identity. Record both sides' original candidate count, uniquely excluded count by selection stage, retained count, retained center span, actual retained raw support, half-width, method, speed span, retained signed-nonpositive count and source-attributed event/condition evidence. For auditable exclusions, retain or reproducibly identify center times and their raw support endpoints/indices. Preserve the original support summary alongside the new summary in the comparison artifact. A count invariant such as `originalCandidates = lowSpeedExcluded + eventExcludedUnique + retained` is useful if low-speed screening precedes event screening; overlapping burnout/recovery reasons must not double-count a center. The current persistence invariant only allows low-speed exclusions (`dragCalibration.ts:173–181`), so versioned parsing must change deliberately.

Legacy records without full provenance keep their existing multiplier and unverified label; do not silently refit, revoke or upgrade them. Existing CAL-E1 reviewed records retain their old selection-policy meaning and must not acquire CAL-E2 status by loading. Strict parsing should reject inconsistent new counts, bounds, policy IDs or result/evidence associations. Reopened new records must reproduce conditional eligibility from their retained support and the exact stored evidence.

## Required controlled acceptance checks

- **Neighborhood preservation:** both velocity-line and altitude-quadratic paths; regular, irregular and sparse cadence; actual support differs from center ± nominal width; event-straddling centers are removed while each retained point's fitted velocity/acceleration and all regression inputs exactly match its original derivation. Include a center inside coast whose neighborhood crosses burnout or recovery, exact boundary equalities, and widening event uncertainty. Check that no alternative proxy/window or narrower fit is recomputed.
- **Failure and boundary handling:** no centers, 9 versus 10 survivors, overlapping/reversed/nonfinite event bounds, absent-through endpoint coverage, missing source/clock evidence, missing one side's events, truncated records and boundary proxies. Nonfinite/duplicate-time/singular local fits must not become newly usable through this selector; retain existing invalid-fit behavior and report failures. A time-shifted copy with correspondingly shifted own-clock events should retain the same physical centers and values, without cross-aligning model and log clocks.
- **Signed regression and cancellation:** keep eligible zero/negative inferred accelerations, including an excluded positive point and a retained negative point, to detect outcome-dependent selection. Signed OLS numerator cancellation can yield zero/negative effective Cd; reject an unusable ratio rather than taking absolute values, clipping coefficients or restoring excluded centers. Zero/nonfinite design denominator, nonfinite coefficient/residual, or too few points fails closed. Preserve operational bounds; do not introduce a fitted “safe” numerical cutoff.
- **Eligibility and lifecycle:** complete events plus unverified or unsupported motion/mass remains analysis-only; a known mass change overrides supportive review. Exercise explicit refit/apply, stale evidence/input edits, failed/canceled/obsolete refits, replacement of a legacy adjustment, save/reopen, and legacy CAL-E1 compatibility. Tests should establish that all source identities, exclusion counts and actual supports survive persistence.
